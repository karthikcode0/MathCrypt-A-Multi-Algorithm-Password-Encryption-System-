#MathCrypt-A-Multi-Algorithm-Password-Encryption-System

**## 1. Project Description**

MathCrypt is a Python-based password encryption project that uses multiple mathematical algorithms and properties to transform a user-provided password into an encoded output.

Instead of relying on a single mathematical operation, MathCrypt combines different mathematical properties to generate an encrypted representation of the password.

The mathematical properties used in the project include:

* Factors
* Prime number checking
* Prime factors
* Digit sum
* Reverse of digits
* Binary conversion
* Factorial of digits
* Sign checking

The different results are combined to generate the final encrypted password.


**## 2. Features**

MathCrypt provides the following features:

* Accepts a password or numerical input from the user
* Calculates the factors of the input
* Checks whether the input is prime
* Finds the prime factors
* Calculates the sum of digits
* Reverses the digits
* Converts the input into binary
* Calculates the factorial of individual digits
* Performs sign checking
* Combines the results of multiple mathematical operations
* Generates a final encrypted output

**## 6. How MathCrypt Works**

MathCrypt processes the input through multiple mathematical operations.

### Step 1: Input

The user provides the required password or numerical input.

### Step 2: Mathematical Processing

The input is processed using different mathematical properties, including:

1. **Factors**
   The program finds the factors associated with the input.

2. **Prime Check**
   The program checks whether the input is a prime number.

3. **Prime Factors**
   The program determines the prime factors of the input.

4. **Digit Sum**
   The digits of the input are added together.

5. **Reverse**
   The digits are reversed.

6. **Binary Conversion**
   The input is converted into its binary representation.

7. **Factorial of Digits**
   The factorial of the individual digits is calculated.

8. **Sign Check**
   The program checks the sign of the input.

### Step 3: Encryption

The results obtained from the different mathematical operations are combined according to the encryption logic implemented in the program.

This produces the final encrypted output.

**## 8. Project Concept**

MathCrypt is based on the idea of combining multiple mathematical transformations to create an encoded representation of an input.

Each mathematical operation produces a different result. These results are then combined to form the final encrypted output.

The project demonstrates how mathematical concepts can be combined using Python programming techniques to build a basic encryption-oriented application.
